# Contexto de Claude Code

Lee y aplica `AGENTS.md` como fuente común de instrucciones del proyecto. Lee después `README.md`, `docs/ESPECIFICACION.md`, `docs/AUDITORIA.md` y el estado de trabajo en `docs/STATUS.md` si existe.

Este archivo evita mantener dos constituciones divergentes. Claude Code con Fable 5.1 y Codex con GPT Astra comparten contratos, fases y criterios de aceptación. El modelo seleccionado en la herramienta no cambia el objetivo del repositorio.

Consulta `PROMPTS.md` para el arranque y los relevos. No conviertas esta documentación en una simple demo con salidas constantes: el resultado final debe entrenar, guardar, recargar y servir un evaluador real.
